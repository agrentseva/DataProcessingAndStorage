### Асинхронный обход ресурсов HTTP-сервера.

#### Задачи программы:

1. Программа должна **подключаться к HTTP-серверу** по указанному адресу и порту и начинать обход с корневого пути `/`.
2. Сервер возвращает JSON с полями `message` и `successors`, содержащими сообщение и список следующих ресурсов.
3. Программа должна **асинхронно запрашивать найденные ресурсы** и обходить все доступные пути.
4. Каждый ресурс должен **запрашиваться не более одного раза**, даже если на него ссылаются несколько других ресурсов.
5. Программа должна **собирать сообщения** из всех полученных ответов и выводить их в лексикографическом порядке.
6. Программа должна **дождаться завершения всех запросов** перед выводом результата.

#### Техническая часть:

1. Для выполнения HTTP-запросов используется `java.net.http.HttpClient`.
2. Для асинхронного обхода используются **виртуальные потоки Java 21** через `Executors.newVirtualThreadPerTaskExecutor()`.
3. Для хранения посещённых путей используется потокобезопасное множество на основе `ConcurrentHashMap`.
4. Для ожидания завершения всех задач используется `Phaser`.
5. Для обработки JSON используется библиотека Jackson.
6. Программа должна обрабатывать ошибки HTTP-запросов и прерывания потоков.

---

#### Команды для терминала:

1. **Запуск сервера:**
`java -jar Task_J3-server.jar student_id`

2. **Запуск программы:**
`./gradlew run --args="localhost 8080"`
