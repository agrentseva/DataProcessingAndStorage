### Многопоточная сортировка связного списка.

#### Задачи программы:
1. Главный поток считывает введённые пользователем строки и **добавляет их в начало связного списка**.
2. Строки длиной более 80 символов **могут разбиваться на части**. 
3. При вводе пустой строки программа **выводит текущее содержимое списка**.
4. Для сортировки списка запускается **настраиваемое количество дочерних потоков**.
5. Дочерние потоки выполняют **бесконечную пузырьковую сортировку**. Каждый проход должен обходить весь список.
6. Должна быть предусмотрена возможность задавать **задержку между шагами сортировки и внутри шагов**.
7. Один шаг сортировки — это **попытка поменять местами два соседних элемента**.
8. При перестановке элементов необходимо **переставлять узлы связного списка**, а не менять местами значения строк внутри узлов.
9. Список должен реализовывать интерфейс `Iterable`. Для вывода содержимого необходимо использовать стандартный цикл `for-each`.
10. Во время задержек между шагами пользователь должен иметь возможность видеть текущее, в том числе ещё не отсортированное, содержимое списка.
11. Количество и содержимое выводимых строк должны соответствовать ранее введённым данным.
12. **Блокировка всего списка на время сортировки запрещена.** Необходимо организовать синхронизацию так, чтобы избежать взаимных блокировок (`deadlock`). При захвате записей сначала необходимо блокировать те, которые находятся ближе к голове списка.

---

#### Вторая реализация:
1. Необходимо заменить собственный связный список на `ArrayList`, обёрнутый в `Collections.synchronizedList()`.
2. Адаптировать алгоритм сортировки для работы со стандартной реализацией списка, сохранив предусмотренные задержки.

2. **Измерить фактическое количество шагов** для обеих реализаций.
3. Сравнить теоретические и фактические результаты и объяснить полученные различия.
